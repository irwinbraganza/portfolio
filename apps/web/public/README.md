# Public Assets

This directory contains static assets served by the web app.

## resume.pdf

A PDF version of your resume. To add your actual resume:

1. Generate or export your resume as a PDF
2. Name it `resume.pdf`
3. Place it in this directory (`apps/web/public/`)
4. The resume download button will link to `/resume.pdf`

## og-image.png

Open Graph image displayed when sharing the portfolio on social media.

Recommended dimensions: 1200 x 630 pixels

You can create this using:
- Design tools (Figma, Canva)
- Screenshot of your hero section
- Custom designed image

## favicon.ico

Site favicon displayed in browser tabs. Optional but recommended.
